Run `python download_data.py` to retrieve the pinned file. Preserve UCI attribution
when redistributing or adapting it. Raw data are intentionally omitted from the
shareable starter ZIP; the download script recreates the input.

Historical observational Taiwanese credit data; not current Indian lending data.
Do not interpret stored monthly history as editable actions or independent future
cohorts. Pilot numeric treatment of repayment-status codes is a known limitation.
